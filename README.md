# AudioShow

Android-приложение для **непрерывной 24/7 записи** звука окружения.

## Возможности

- Непрерывная запись с микрофона (Foreground Service)
- Автоматическое сохранение отрывками по **15 минут**
- Имена файлов: `21:00 - 1 ноября 2026г.m4a`
- Встроенный проигрыватель: нажми на запись → слушай
- Обрезка начала/конца и сохранение в **Download/AudioShow**
- ИИ-анализ через Google Gemini (нужен API-ключ)
- Автозапуск после перезагрузки (опционально)

## Package

`com.audioshow.ms`

## Сборка

```bash
./gradlew assembleDebug
```
